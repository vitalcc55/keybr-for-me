# Режим работы с персональным Keybr

Репозиторий — локальный Windows-ориентированный производный Keybr для одного пользователя. Архитектурный и исполнительный контракт находится в [docs/personal-keybr-execplan.md](docs/personal-keybr-execplan.md); он связывает GitHub issues #1–#7 и задаёт порядок `#2 → #3 → #4 → #5 → #6 → #7`.

Сохраняй штатные словари, модели, layout/statistics identity и существующий toolchain. Персональный корпус и модель подключаются как отдельный источник через минимальный общий descriptor. Не добавляй новый backend, базу данных, test framework, telemetry/observability platform или параллельный launcher без воспроизводимого блокера приёмки. Тесты выполняй только с изолированными временными `DATA_DIR` и SQLite; реальные локальные данные не удаляй и не перезаписывай.

Субагенты используются только для read-only research/review. Основной агент владеет синтезом, правками, проверками и коммитами. Перед финальным коммитом пройди focused checks, профильный review-loop, затем полный verify и browser acceptance из ExecPlan.
